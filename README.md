# CraftHost 🚀 | Minecraft Control Panel & Hosting Simulation

CraftHost, tamamen frontend teknolojileri kullanılarak geliştirilmiş, sunucu taraflı (backend) hiçbir maliyeti olmayan **tarayıcı tabanlı bir Minecraft Sunucu Yönetim Paneli Simülasyonudur**. 

Bu proje, gerçek bir hosting panelinin (Pterodactyl vb.) sunduğu kullanıcı deneyimini, kaynak yönetimini ve oyun ayarları mekanizmalarını tarayıcı üzerinde görsel ve dinamik bir illüzyonla canlandırmak amacıyla tasarlanmış **benzersiz (unique) bir frontend projesidir**.

🔗 **Canlı Demo:** [crafthostpanel.netlify.app](https://netlify.app)

---

## ✨ Öne Çıkan Özellikler

* 💾 **Sıfır Sunucu Maliyeti (Serverless Mimarisi):** Kullanıcı kayıtları, sunucu oluşturma verileri ve tüm panel konfigürasyonları tamamen tarayıcının yerel hafızasında (`localStorage`) güvenle saklanır.
* 📊 **Dinamik Performans Takibi:** Sunucu durumuna (Açık/Kapalı) bağlı olarak simüle edilen anlık CPU, RAM ve Disk alanı grafiksel takibi.
* ⚙️ **Gelişmiş Dünya & Oyun Ayarları:** Oyun modu seçimi, zorluk seviyesi, Java/Bedrock (GeyserMC) çapraz platform desteği ve detaylı oyun kuralları (PvP, Whitelist, Nether vb.) yönetimi.
* 🖥️ **Canlı Konsol & CMD Simülatörü:** Tıpkı gerçek sunucularda olduğu gibi canlı log çıktıları akışı ve komut satırı deneyimi.
* 🌐 **IP ile Dünyaya Katılma İllüzyonu:** Geliştirilen özel chat modülü sayesinde sanal bir IP ile Minecraft dünyasına bağlanma, Ping/FPS göstergeleri ve simüle edilmiş oyun içi sohbet akışı.
* 🔌 **Eklenti (Plugin) & Yedekleme Alanı:** Tek tıkla sanal eklenti yükleme ve veri yedekleme adımlarının arayüz simülasyonu.

---

## 🛠️ Kullanılan Teknolojiler

Bu projenin geliştirilme sürecinde **Gemini yapay zeka asistanlığı** ile birlikte modern ön yüz teknolojileri harmanlanmıştır:

* **HTML5:** Yapısal semantik bileşenler ve form yönetimi.
* **CSS3:** Modern, duyarlı (responsive) ve karanlık mod odaklı oyuncu temalı arayüz tasarımı.
* **Vanilla JavaScript (ES6+):** Durum yönetimi (State Management), asenkron simülasyon döngüleri ve log akış mimarisi.
* **Web Storage API (`localStorage`):** Kalıcı veri saklama katmanı.

## 🚀 Projeyi Yerelde Çalıştırın

Projeyi kendi bilgisayarınızda çalıştırmak oldukça basittir, herhangi bir `npm install` veya veritabanı kurulumu gerektirmez:

1. Bu depoyu klonlayın:
   ```bash
   git clone https://github.com
   ```
2. Proje klasörüne gidin:
   ```bash
   cd crafthost-panel
   ```
3. `index.html` dosyasını tarayıcınızda açın veya bir `Live Server` eklentisiyle çalıştırın.
